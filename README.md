# 図解キット

AIの答えが長くて読む気にならないとき、**1枚の図解HTMLに変える**ためのキットです。

使い方は2通り。**どちらか片方でいい**です。

---

## A. チャットに貼るだけ（ChatGPT / Claude / Gemini）

ふだんブラウザでAIを使っている人はこちら。インストールは要りません。

👉 **[PROMPT.md](PROMPT.md)** を開いて、枠の中をコピーして送るだけ。

長い回答が返ってきた直後に貼ると、その内容が図解HTMLになって出てきます。

---

## B. Claude Code のスキルとして入れる

Claude Code を使っている人はこちら。毎回プロンプトを貼らなくてよくなります。

1. `zukai/` フォルダごと、プロジェクトの `.claude/skills/` の中にコピーする
2. Claude Code で「図解にして」または `/zukai` と打つ

`zukai/template.html` が器で、Claude がその中身だけを差し替えます。

---

## 何ができるか

内容に応じて、この5つの型から**合うものだけ**が選ばれます。

| 型 | 使われる場面 |
|---|---|
| 手順 | やることに順番があるとき |
| 流れ | 入口 → 処理 → 出口があるとき |
| 比較 | 前後・良し悪しがあるとき |
| 表 | 項目 × 観点で並ぶとき |
| 数字 | 効果が数字で言えるとき |

見た目は3つのルールで固定しています。

- 影とグラデーションを使わない（面の差と1pxの線だけで階層を作る）
- 有彩色は1色だけ
- ダーク／ライト／システムの3択に対応（右上のボタン）

## 注意

- **AIが作った図解は、元の回答が正しいことを保証しません。** 中身の正しさは必ず自分で確かめてください
- 元の内容にない数字や手順を足さないよう指示してありますが、まれに補って書くことがあります
